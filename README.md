# Fresco Food Finder

Crea una aplicación web llamada FRESCO. La aplicación permite que los usuarios ingresen los alimentos que tienen en casa. Una IA analiza esos alimentos y genera varias recetas posibles, priorizando aquellos que están próximos a vencer. Debe tener una página de inicio, sección para ingresar alimentos, resultados de recetas y una sección de planes de pago.
